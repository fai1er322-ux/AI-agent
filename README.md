# AI-agent

## QA Skills

This repo vendors [petrkindlmann/qa-skills](https://github.com/petrkindlmann/qa-skills) under
[`.skills/qa-skills`](.skills/qa-skills) — 50 QA and test-automation skills (Playwright, Cypress,
API/unit/mobile testing, test strategy, CI/CD, accessibility, security, AI-assisted QA, and more)
following the [Agent Skills Standard](https://agentskills.io), usable by Claude Code and other
compatible agents. See [`.skills/qa-skills/README.md`](.skills/qa-skills/README.md) for the full
skill list and usage.
